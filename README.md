# Movie Library — личная кинотека

**Автор:** Караповский Ярослав
**Язык:** Python 3.8+
**Библиотеки:** Tkinter (стандартная), json

## Описание
Графическое приложение для хранения и фильтрации информации о фильмах. Позволяет добавлять фильмы с валидацией ввода (год — число, рейтинг — от 0 до 10), сохранять и загружать данные из файла `data/movies.json`, а также фильтровать фильмы по жанру и году выпуска.

## Требования
- Python 3.8+
- Установить зависимости:
  pip install -r requirements.txt

## Запуск приложения
1. Клонируйте репозиторий:
   git clone https://github.com/yourname/MovieLibrary.git
   cd MovieLibrary
2. Запустите:
   python movie_library.py
3. Используйте интерфейс для добавления и фильтрации фильмов.

## Примеры использования
- Добавьте фильм: введите все поля и нажмите «Добавить фильм».
- Фильтрация: введите жанр или год и нажмите «Фильтровать».
- Данные сохраняются автоматически в `data/movies.json`.

## Возможные тесты (по желанию)
- Попробуйте ввести некорректный год (например: «двадцать двадцать»).
- Введите рейтинг больше 10 или меньше 0.
- Проверьте фильтрацию по жанру и году.
- Перезапустите приложение — данные должны сохраниться.
