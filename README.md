# Movie Library — личная кинотека
# Сделано в рамках проекта "Код Будущего"

**Автор:** Караповский Ярослав
**Язык:** Python 3.8+
**Библиотеки:** Tkinter (стандартная), json

## Описание
Графическое приложение для хранения и фильтрации информации о фильмах. Позволяет добавлять фильмы с валидацией ввода (год — число, рейтинг — от 0 до 10), сохранять и загружать данные из файла `data/movies.json`, а также фильтровать фильмы по жанру и году выпуска.

## Требования
- Python 3.8+
- Установить зависимости:
  pip install -r requirements.txt

## Запуск приложения
1. Клонируйте репозиторий:
   git clone https://github.com/YAZShadoW/Movie-Library.git
   cd MovieLibrary
2. Запустите:
   python movie_library.py
3. Используйте интерфейс для добавления и фильтрации фильмов.

## Примеры использования
- Добавьте фильм: введите все поля и нажмите «Добавить фильм».
- Фильтрация: введите жанр или год и нажмите «Фильтровать».
- Данные сохраняются автоматически в `data/movies.json`.

## Возможные тесты (по желанию)
- Попробуйте ввести некорректный год (например: «двадцать двадцать»).
- Введите рейтинг больше 10 или меньше 0.
- Проверьте фильтрацию по жанру и году.
- Перезапустите приложение — данные должны сохраниться.

## Примеры

Название: «Начало»
Жанр: «Фантастика»
Год: 2010
Рейтинг: 8.8

Название: «Титаник»
Жанр: «Драма»
Год: тысяча девятьсот девяносто седьмой
Рейтинг: 7.8
Нажмите «Добавить фильм». Появится окно с ошибкой: «Год — целое число, рейтинг — число от 0 до 10».

**Пример 3** (ошибка валидации — рейтинг вне диапазона):

Жанр: «Ужасы»

Рейтинг: 15
Нажмите «Добавить фильм». Появится то же окно с ошибкой.

## Фильтрация списка фильмов
В нижней части окна есть поля для фильтрации.
**Фильтр по жанру:**
Введите в поле «Фильтр по жанру»: Фантастика.
Нажмите кнопку «Фильтровать».
В таблице останутся только фильмы, у которых в поле «Жанр» указано «Фантастика».

**Фильтр по году:**
Введите в поле «Фильтр по году»: 2010.
Нажмите кнопку «Фильтровать».
В таблице останутся только фильмы, выпущенные в 2010 году.
